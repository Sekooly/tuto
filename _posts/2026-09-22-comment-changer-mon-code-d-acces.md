Vous venez de vous connecter et vous souhaitez modifier votre code d'accès ? Voici comment faire.

**Prérequis :** connaître votre **ancien code d'accès**.

## 1. Ouvrez votre profil

En haut à droite, cliquez sur **Mon profil**.
![Menu mon profil](/assets/img/menu-mon-profil.PNG)

## 2. Rendez-vous dans « Code d'accès »

Descendez tout en bas de la page : la section **Code d'accès** est modifiable directement.
![Code d'accès](/assets/img/modifier-code-acces.PNG)

## 3. Saisissez votre ancien et votre nouveau code

Saisissez d'abord votre **ancien code**, obligatoire : sans lui, la modification est impossible. Saisissez ensuite le **nouveau code** souhaité.
![champs « ancien code » et « nouveau code » remplis](/assets/img/deux-codes-remplis.PNG)

## 4. Corrigez en cas d'erreur

Si l'ancien code est erroné, la modification est refusée. Ressaisissez-le correctement.
![modification refusée](/assets/img/code-modif-erroné.PNG)

## 5. Validez
Un message confirme que votre code d'accès a été **modifié avec succès**.
![modification validée](/assets/img/code-modif-ok.PNG)
